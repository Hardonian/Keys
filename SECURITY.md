# Security Policy

## Supported Versions
Security updates apply to the `main` branch. If you depend on tagged releases, upgrade to the latest release before reporting issues.

## Reporting a Vulnerability
Please report security issues privately.

1. Open a private GitHub Security Advisory on this repository.
2. Include reproduction steps, impact assessment, and any relevant logs or screenshots.

Do not open public issues for security vulnerabilities.

## Response Timeline
We aim to acknowledge reports within 5 business days and will provide a remediation plan or status update as soon as we can.
