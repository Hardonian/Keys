# Governance

## Project Ownership
KEYS is maintained by the project maintainers. Maintainers are responsible for roadmap decisions, releases, and enforcing contribution standards.

## Decision Making
- Day-to-day changes are decided through pull requests.
- Significant changes should be proposed in GitHub Discussions before implementation.
- Maintainers make final decisions when consensus cannot be reached.

## Contributions
All contributions must follow `CONTRIBUTING.md` and the Code of Conduct.

## Community Spaces
- GitHub Issues: bug reports and feature requests
- GitHub Discussions: questions, ideas, and design reviews
