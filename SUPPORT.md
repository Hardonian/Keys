# Support

## Where to Get Help
- **Questions and troubleshooting:** GitHub Discussions
- **Bug reports:** GitHub Issues with the bug report template
- **Feature requests:** GitHub Issues with the feature request template

## What to Include
- Environment details (OS, Node version, package manager)
- Steps to reproduce or a minimal example
- Relevant logs or screenshots

## Security Issues
Security vulnerabilities should be reported privately via `SECURITY.md`.
